# 内定者フォロー管理ダッシュボード

内定者アンケート運用スプレッドシートの**サマリ（フォーム別回答率・個人別実施状況・未回答者）**を、
WEB 上の管理画面として確認できるようにするものです。

対象スプレッドシート: [内定者フォロー管理（管理スプレッド）](https://docs.google.com/spreadsheets/d/1PcOTO3IG9Hgt9iuQqrCBgdQOxmvVissxliP0hHmLwqs/edit)

## 画面でわかること

| ブロック | 内容 |
| --- | --- |
| **全体サマリ（KPI）** | 全体実施率 / 集計対象者数 / 未回答（要対応）件数 / 全項目完了者数 |
| **フォーム別 回答状況** | フォームごとの回答率・回答済/未回答人数・期日・期限超過/期限前 |
| **要対応（未回答者）** | 「期限超過」「要リマインド」別に未回答者を一覧。フォーム単位で**メールアドレスを一括コピー**でき、そのままリマインド送信に使えます |
| **個人別 実施状況** | 対象者 × 各フォームの ◯/－ マトリクス。氏名検索・「未完了のみ / 未着手 / 完了」フィルタ付き |

集計ロジックはスプレッドシート本体と一致させています（対象＝内定者マスタの「対象」、
◯/－ は照合チェック＝回答済・未回答リスト＝未回答から再構成、表記ゆれは氏名別名で補正）。

## 2つの使い方（同期方式）

### ① スナップショット版 — `dashboard/index.html`
- **単一の HTML ファイル**。ダブルクリックでブラウザで開くだけ。サーバー不要。
- レイアウト確認用に **架空のサンプルデータ** を埋め込んでいます（リポジトリに実在の個人情報は含めません）。
- 実データ入りのスナップショットが必要な場合は、ライブ同期版で表示するか、別途生成してください。
- 用途: 見た目の確認 / テンプレートとしての流用。

### ② ライブ同期版（推奨） — `apps-script/`
- **Google Apps Script のウェブアプリ**。開く／「更新」を押すたびにスプレッドシートの最新値を読み込みます。
- データは Google の外に出ず、アクセスも Google アカウントで制御できる（個人情報管理上こちらが安全）。
- 用途: 常に最新の状態を URL で確認・共有したいとき。

#### セットアップ手順（②ライブ同期版）
1. 対象スプレッドシートを開く → メニュー **拡張機能 › Apps Script**
2. `Code.gs` の中身を貼り付け（既存の集計コードとは別ファイルにしてOK。関数名が重複しないよう注意）
3. ファイルを追加 **＋ › HTML** で `Page` を作成し、`apps-script/Page.html` の中身を貼り付け
4. **デプロイ › 新しいデプロイ › 種類「ウェブアプリ」**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **組織内**（`appsscript.json` の `access: "DOMAIN"`）
5. 発行された URL を開く → 管理画面が表示されます

> タブ名が多少違っても動くよう、キーワード（内定者マスタ / フォーム一覧 / 未回答リスト / 照合チェック / 氏名別名）でタブを自動探索します。
> 読み込みエラーが出る場合は、これらのタブ名が変更されていないかご確認ください。

## ファイル構成

```
dashboard/
  index.html        スナップショット版（単体で開ける）
apps-script/
  Code.gs           ウェブアプリのサーバー側（スプレッドシート読み取り）
  Page.html         ウェブアプリの画面（Code.gs から呼ばれる）
  appsscript.json   マニフェスト（タイムゾーン / ウェブアプリ設定）
README.md
```

## 個人情報の扱い

本ダッシュボードは**サマリ**（氏名・回答状況・実施率・連絡用メール）のみを表示します。
式典フォーム等の回答内にある住所・電話番号・保護者情報などの生データは含みません。
